# Geno · cartago-web

Interactive explorer for the *Índice de los Protocolos de Cartago* (Costa Rica, 1540–1839):
a map, a timeline and a people network built from 11,053 notarial records extracted with Gemini.

React 19 + Vite + Tailwind v4, MapLibre GL (CARTO dark basemap) and react-force-graph-2d.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production bundle in dist/
npm run lint
```

## Data

The app reads three minified files from `public/data/`, generated by `../scripts/generate_json_views.py`
from `../scripts/data/gemini_output/*.jsonl`:

| file | contents |
| --- | --- |
| `events.json` | one compact record per event: id, year (`y`), inferred-year flag (`yi`), date, people, places, `[lat, lng]` and canonical place name |
| `text_en.json` | English summaries, aligned by index with `events.json` |
| `text_es.json` | Spanish summaries, aligned by index (`null` falls back to English) |

Regenerate after changing the gazetteer or the extraction output:

```bash
python ../scripts/generate_json_views.py
```

The script prints the most frequent place names it could not geolocate; add them to
`GAZETTEER` / `ALIASES` to improve map coverage. Records with no year inherit the year of the
previous dated record (the index is chronological) and are flagged with `≈` in the UI.

## Structure

```
src/
  App.jsx                 shell: language, active view (URL hash), shared time window, cross-view jumps
  lib/data.js             fetch + module cache, derived indexes (histogram, people, co-occurrence graph)
  lib/i18n.js             ES / EN strings
  lib/text.js             accent-insensitive folding and highlighting
  components/MapView      clustered bubble map (GeoJSON source + GPU layers), popup with the records of a place
  components/TimeControls year histogram, slider, window size, play/pause, inferred-year toggle
  components/TimelineView searchable, decade-filtered, incrementally rendered list
  components/GraphView    ego-network explorer (top-N or a person's neighbourhood)
  components/EventDetail  one record, shared by the three views
```

Each view is lazy-loaded, so MapLibre and the force-graph engine are only downloaded when needed.
